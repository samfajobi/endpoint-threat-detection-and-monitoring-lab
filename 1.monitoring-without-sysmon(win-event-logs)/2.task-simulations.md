# 🔬 Practical Monitoring Tasks (Hands-On Scenarios)

---

## 🧪 Task 1 — Failed Login Detection

1. Attempt wrong password multiple times.
2. Open Security Log.
3. Filter for:
```
Event ID: 4625
```

Observe:
* Source IP
* Account name
* Logon type

---

## 🧪 Task 2 — Process Monitoring

Run:

```
cmd.exe
powershell.exe
notepad.exe
```

Check:

```
Event ID 4688
```

Observe:
* Parent process
* Command line
* Account used

---

## 🧪 Task 3 — Privilege Escalation Simulation

1. Create a new local user:
```
net user testuser Password123 /add
```

2. Add to Administrators:
```
net localgroup administrators testuser /add
```

Check:
* 4720
* 4732

---

## 🧪 Task 4 — PowerShell Execution Monitoring

Run:

```
powershell -ExecutionPolicy Bypass -Command "Get-Process"
```

Check:
* Event ID 4688
* Event ID 4104

---

## 🧪 Task 5 — Persistence Simulation

Create a scheduled task:

```
schtasks /create /sc minute /mo 5 /tn TestTask /tr notepad.exe
```

Check:
* Security log (Task creation)
* System log (Service interactions)

---

## 🧪 Task 6 — Service Installation Monitoring

Create a test service:

```
sc create TestService binPath= "C:\Windows\System32\notepad.exe"
```

Check:
```
System Log → Event ID 7045
```
