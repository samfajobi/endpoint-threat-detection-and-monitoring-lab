# Attack Simulations

## Overview

This document lists all simulated attack scenarios performed in the SOC lab environment using:

- Windows Endpoint
- Sysmon
- Windows Event Logs
- Wazuh SIEM

Each simulation mimics real-world adversary techniques mapped to MITRE ATT&CK.

---

# 1. Discovery – PowerShell Reconnaissance

## Simulation

```powershell
whoami
whoami /priv
ipconfig /all
net user
net localgroup administrators
systeminfo
```

- T1069 – Permission Group Discovery
