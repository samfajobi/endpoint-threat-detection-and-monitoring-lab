# Detection Logic

## Overview

This document defines detection strategies and log sources for each simulated attack. Detection is based on:

- Sysmon Event Logs
- Windows Security Logs
- Wazuh correlation rules

---

# 1. PowerShell Reconnaissance

## Log Sources

- Sysmon Event ID 1
- Windows Event ID 4688

## Detection Logic

- Detect multiple recon commands within short timeframe
- Identify execution of:
  - whoami
  - net user
  - systeminfo
  - ipconfig

## Example Detection Condition

- 5+ recon-related commands executed within 3 minutes by same user

---

# 2. Encoded PowerShell

## Log Sources

- Event ID 4104 (Script Block Logging)
