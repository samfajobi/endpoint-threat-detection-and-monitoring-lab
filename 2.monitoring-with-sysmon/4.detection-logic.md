# Detection Logic

## Overview

This document defines detection strategies and log sources for each simulated attack. Detection is based on:

- Sysmon Event Logs
- Windows Security Logs
- Wazuh correlation rules

---

# 1. PowerShell Reconnaissance

## Log Sources

- Sysmon Event ID 1
- Windows Event ID 4688

## Detection Logic

- Detect multiple recon commands within short timeframe
- Identify execution of:
  - whoami
  - net user
  - systeminfo
  - ipconfig

## Example Detection Condition

- 5+ recon-related commands executed within 3 minutes by same user

---

# 2. Encoded PowerShell

## Log Sources

- Sysmon Event ID 1
- Event ID 4104 (Script Block Logging)

## Detection Logic

- CommandLine contains "-EncodedCommand"
- Presence of long base64 string pattern

## High Risk Indicator

- Encoded PowerShell launched by non-admin user

---

# 3. Suspicious Parent-Child Process

## Log Sources

- Sysmon Event ID 1

## Detection Logic

- ParentImage = cmd.exe
- Image = powershell.exe

OR

- ParentImage = winword.exe
- Image = powershell.exe

Flag abnormal parent-child combinations.

---

# 4. Credential Access (LSASS Monitoring)

## Log Sources

- Sysmon Event ID 10 (Process Access)
- Sysmon Event ID 1

## Detection Logic

- TargetImage contains lsass.exe
- Suspicious process requesting access

Severity increases if non-system process interacts with LSASS.

---

# 5. Registry Persistence

## Log Sources

- Sysmon Event ID 13

## Detection Logic

- TargetObject contains:
  - \CurrentVersion\Run
  - \CurrentVersion\RunOnce

Alert on registry value creation or modification.

---

# 6. Service Creation

## Log Sources

- Windows Event ID 4697
- Sysmon Event ID 1

## Detection Logic

- New service created
- Service binary path suspicious (user directories, temp, cmd.exe)

---

# 7. Suspicious Network Activity

## Log Sources

- Sysmon Event ID 3
- Sysmon Event ID 22

## Detection Logic

- Repeated outbound connections to same IP
- Rare DNS queries
- External connections initiated by PowerShell

---

# 8. File Drop + Execution

## Log Sources

- Sysmon Event ID 11
- Sysmon Event ID 1

## Detection Logic

- Executable created in:
  - C:\Users\Public\
  - Downloads
  - Temp directories
- Immediate execution after file creation

---

# 9. RDP Monitoring

## Log Sources

- Windows Event ID 4624 (Logon Type 10)
- Event ID 4625

## Detection Logic

- Multiple failed RDP attempts
- RDP login outside working hours
- RDP from unusual IP range

---

# 10. Admin Group Modification

## Log Sources

- Event ID 4732

## Detection Logic

- User added to Administrators group
- Account previously not privileged

Escalate severity if performed outside change window.
