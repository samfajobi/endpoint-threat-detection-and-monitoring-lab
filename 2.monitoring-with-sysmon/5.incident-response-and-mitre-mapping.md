#  Incident Response Playbook

## Overview

This document defines investigation and response procedures for each detected attack scenario.

Each response follows:

1. Identification  
2. Investigation  
3. Containment  
4. Eradication  
5. Recovery  
6. Lessons Learned  

---

# 1. PowerShell Reconnaissance

## Investigation

- Identify user account
- Review command history
- Determine intent

## Containment

- Monitor user activity
- Restrict PowerShell usage if necessary

## Eradication

- Remove unauthorized tools

## Recovery

- Reset compromised accounts if required

---

# 2. Encoded PowerShell

## Investigation

- Decode base64 string
- Analyze script behavior
- Identify source user

## Containment

- Terminate PowerShell process
- Isolate endpoint if malicious

## Eradication

- Remove malicious scripts
- Block similar execution via policy

## Recovery

- Monitor for recurrence

---

# 3. Suspicious Parent-Child Process

## Investigation

- Analyze process tree
- Identify initial execution vector

## Containment

- Kill suspicious process
- Block malicious document if applicable

## Eradication

- Remove persistence mechanisms

## Recovery

- Harden macro settings

---

# 4. Credential Access

## Investigation

- Identify process accessing LSASS
- Determine legitimacy

## Containment

- Isolate host if suspicious
- Reset affected credentials

## Eradication

- Remove malicious process
- Patch system vulnerabilities

---

# 5. Registry Persistence

## Investigation

- Identify modified registry key
- Review command-line arguments

## Containment

- Remove malicious registry entry

## Eradication

- Scan system for additional persistence

## Recovery

- Enable registry auditing alerts

---

# 6. Malicious Service Creation

## Investigation

- Review service binary path
- Validate service legitimacy

## Containment

- Stop service
- Disable service

## Eradication

- Delete malicious service
- Remove binary

---

# 7. Suspicious Network Activity

## Investigation

- Identify destination IP
- Check threat intelligence (if available)
- Analyze process initiating connection

## Containment

- Block IP at firewall
- Isolate endpoint if necessary

---

# 8. File Drop + Execution

## Investigation

- Identify file hash
- Determine execution timeline
- Check if additional payloads exist

## Containment

- Remove malicious file
- Isolate endpoint if needed

---

# 9. RDP Abuse

## Investigation

- Identify source IP
- Confirm legitimacy of login

## Containment

- Block suspicious IP
- Reset compromised accounts

## Hardening

- Enforce MFA
- Restrict RDP exposure

---

# 10. Admin Group Escalation

## Investigation

- Identify who performed group change
- Verify change approval

## Containment

- Remove unauthorized admin membership

## Recovery

- Audit other privileged groups
