#  Incident Response Playbook

## Overview

This document defines investigation and response procedures for each detected attack scenario.

Each response follows:

1. Identification  
2. Investigation  
3. Containment  
4. Eradication  
5. Recovery  
6. Lessons Learned  

---

# 1. PowerShell Reconnaissance

## Investigation

- Identify user account
- Review command history
- Determine intent

## Containment

- Monitor user activity
- Restrict PowerShell usage if necessary

## Eradication

- Remove unauthorized tools

## Recovery

- Reset compromised accounts if required

---

# 2. Encoded PowerShell

## Investigation

- Decode base64 string
- Analyze script behavior
- Identify source user

## Containment

- Terminate PowerShell process
- Isolate endpoint if malicious

## Eradication

- Remove malicious scripts
- Block similar execution via policy

## Recovery

- Monitor for recurrence

---

# 3. Suspicious Parent-Child Process

## Investigation

- Analyze process tree
- Identify initial execution vector

## Containment

- Kill suspicious process
- Block malicious document if applicable

## Eradication

- Remove persistence mechanisms

## Recovery

- Harden macro settings

---

# 4. Credential Access

## Investigation

- Identify process accessing LSASS
- Determine legitimacy

## Containment

- Isolate host if suspicious
- Reset affected credentials

## Eradication

- Remove malicious process
- Patch system vulnerabilities
